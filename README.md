# MAHYA Birthday Page

A simple neon gaming-style birthday page with a glowing heart and MAHYA in the center.

## Preview
Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create a GitHub account at https://github.com/ if needed.
2. Create a new **Public** repository named `mahya-birthday`.
3. Upload these files directly to the repository: `index.html`, `style.css`, `script.js`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. After publishing, the URL will look like `https://YOUR-USERNAME.github.io/mahya-birthday/`.

Replace `YOUR-USERNAME` with your GitHub username. Don't put private information in a public repository.
